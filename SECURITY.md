# Security Policy

## Reporting a vulnerability

If you find a security issue (e.g. a way to read/write loot data without the
`INGEST_API_KEY`, or an injection vector in the API), please **do not open a
public issue**. Instead, use GitHub's private reporting:

1. Go to the repo's **Security** tab → **Report a vulnerability**.
2. Describe the issue and, if possible, steps to reproduce.

You'll get an acknowledgment as soon as possible, and a fix or mitigation
will be prioritized before any public disclosure.

## Scope

This is a small self-hosted project (Cloudflare Pages + D1). There's no
bug bounty, but responsible disclosure is appreciated and credited in
release notes if you'd like.
